# IAM Privilege-Escalation Path Finder

Portfolio project for a SOC analyst (2.5 yrs) building toward a cloud 
security researcher role. Priority: correctness of the security logic 
over feature count. Every detector must reflect a real, verifiable AWS 
privilege-escalation mechanic — not just a plausible-sounding permission 
match. Explain WHY in comments, not just WHAT.

Offline tool only. No live AWS calls, no real credentials, no 
account access. Synthetic demo data only.
